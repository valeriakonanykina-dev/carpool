# Попутчик — сервис поиска попутчиков

Учебный проект — веб-приложение для поиска попутчиков для совместных поездок.

## О проекте

«Попутчик» — это сервис, который помогает людям находить попутчиков для совместных поездок. Водители размещают свои маршруты, а пассажиры могут присоединиться к поездке.

### Возможности сервиса

- **Три типа поездок** — «Я водитель», «Ищу попутчиков», «Ищу водителя»
- **Поиск** с автодополнением городов
- **Создание** поездок с указанием маршрута, даты, мест и цены
- **Заявки** — принять, отклонить или отменить
- **Присоединение** к поездкам других пользователей
- **Чат** между попутчиками
- **Отзывы** и рейтинги пользователей
- **Профиль** с ролью (водитель / пассажир) и аватаркой
- **Карта маршрута** на основе OpenStreetMap
- **Чат поддержки** с автоответчиком
- **Тёмная тема**
